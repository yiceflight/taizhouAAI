# 泰州市监测中心智能监测系统

泰州市监测中心智能监测系统 是一个 Tauri 2 + React + TypeScript 桌面客户端。通过 Chrome 插件复用江苏大气站登录态，查询泰州市 K⁺ 小时数据，写入本机 SQLite 数据库并在主界面展示。另保留三个业务网站的网页快照报告功能。

## 小时监测

1. 启动客户端，在 Chrome 扩展管理页重新加载随客户端附带的 v0.7.1 桥接插件。
2. 点击「江苏大气站」，完成平台登录并保持时间序列页面打开。
3. 首页点击「立即同步」，或等待后台自动检查（每 5 分钟）。

固定查询泰州市（城市口径）、K⁺、小时、混合数据，不采集江苏大气站 PM2.5。以北京时间的数据小时为唯一键，重复查询更新原记录；缺测保留为空，不写成 0。首次导入最近 7 天，后续回查 48 小时；离线后的积压按 7 天窗口续传。

主界面显示最新值、最新数据时间和最近 168 条小时记录，数据库保存全部已同步历史。运行期间可暂停自动同步；关闭窗口仍在后台运行，完全退出客户端或 Chrome 后停止查询。会话失效时需重新登录。详见 [小时监测同步](docs/hourly-monitoring.md)。

## 超标巡查计划

自动巡飞默认关闭，开启后以设置中的 K⁺ 阈值判断超标。默认需要人工确认，计划填写后停在最终「确定」前；关闭人工确认后按配置延迟提交，期间支持取消。工作环境、数据时效和天气检查均通过才继续，连续超标去重，历史和缺测数据不触发。填写演练始终不提交。详见 [无人机状态与巡飞调度](docs/drone-dispatch.md)。

## 飞行结束后的 Word 快报

在「报告列表 → 巡飞 Word 快报」读取可飞已结束任务，选择同一航次的司空 Immediate-Media 文件夹，生成包含照片、完整 PM2.5 序列统计与航迹图的 DOCX。PM2.5 判定使用设置中的报告阈值（默认 60 μg/m³），报告同时保存本次阈值快照。报告和原始采样资料保存在本机，可重复生成并打开历史版本。模板随客户端打包，无需 Python 或桌面模板。当前为选定任务后点击生成，不自动触发飞行或自动监控结束。

具体使用步骤、采集上限和校验规则见 [飞行结束 Word 快报](docs/flight-report.md)。

## 工作准备与界面

使用顺序为：连接 v0.7.1 插件 → 验证三个网站 → 读取首批数据并开始监测。历史报告可在未配置时查看。详见 [工作台流程与验证边界](docs/workspace-flow.md)。

## 开发版与正式版插件

运行 `npm run dev:client` / `pnpm tauri dev` 时，会先自动结束占用前端开发端口 1450 的进程，再继续启动；3 秒内未释放则强制结束。设置 `TAURI_DEV_HOST` 时也会清理 HMR 端口 1451。`pnpm dev` 使用相同的端口清理逻辑。

`pnpm dev:client` / `pnpm tauri dev` 使用 `127.0.0.1:14521`，编译时自动生成 `extension-dev/`（插件名称带“开发版”，独立 ID）；`pnpm tauri build` 的安装包使用 `127.0.0.1:14520` 和随包附带的正式插件，`build --debug` 也按正式版处理。两版均从各自客户端的「工作环境」复制插件路径安装，可在同一 Chrome 中并存，不会互抢端口或误收另一版任务。开发插件源码仍统一修改 `extension/`，不要直接编辑生成目录；源码变化后重新编译客户端并在 Chrome 重新加载开发插件。

客户端升级后若插件版本不兼容，会显示不可关闭的强提醒并阻断采集和监测；需在 Chrome 扩展管理页重新加载对应插件。兼容要求由 `bridge-config.json` 的 `minimumExtensionVersion` 标记随客户端构建携带，详见 [在线升级](docs/updater.md)。
