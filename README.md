# 泰州市监测中心智能监测系统

泰州市监测中心智能监测系统 是一个 Tauri 2 + React + TypeScript 桌面客户端。通过 Chrome 插件复用江苏大气站登录态，查询泰州市 K⁺ 与 PM2.5 小时数据，写入本机 SQLite 数据库并在主界面展示。另保留三个业务网站的网页快照报告功能。

## 小时监测

1. 启动客户端，在 Chrome 扩展管理页重新加载随客户端附带的 v0.4.0 桥接插件。
2. 点击「江苏大气站」，完成平台登录并保持时间序列页面打开。
3. 首页点击「立即同步」，或等待后台自动检查（每 5 分钟）。

固定查询泰州市（城市口径）、K⁺、小时、混合数据，PM2.5 使用城市常规数据。以北京时间的数据小时为唯一键，重复查询更新原记录；缺测保留为空，不写成 0。首次导入最近 7 天，后续回查 48 小时；离线后的积压按 7 天窗口续传。

主界面显示最新值、最新数据时间和最近 168 条小时记录，数据库保存全部已同步历史。运行期间可暂停自动同步；关闭窗口仍在后台运行，完全退出客户端或 Chrome 后停止查询。会话失效时需重新登录。详见 [小时监测同步](docs/hourly-monitoring.md)。

## 超标巡查计划

第二步在 K⁺ > 1.0 μg/m³ 时自动打开指定司空项目，按视频规则填写巡查计划，停在最终「确定」前。支持暂停、失败重试与无超标数据的填写演练；连续超标去重，历史和缺测数据不触发。详见 [司空计划准备](docs/flight-plan-preparation.md)。

## 飞行结束后的 Word 快报

在「报告列表 → 巡飞 Word 快报」读取可飞已结束任务，选择同一航次的司空 Immediate-Media 文件夹，生成包含照片、完整 PM2.5 序列统计与航迹图的 DOCX。报告和原始采样资料保存在本机，可重复生成并打开历史版本。模板随客户端打包，无需 Python 或桌面模板。当前为选定任务后点击生成，不自动触发飞行或自动监控结束。

具体使用步骤、采集上限和校验规则见 [飞行结束 Word 快报](docs/flight-report.md)。
