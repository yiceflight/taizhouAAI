# 最小化与后台监测

窗口最小化、被其他窗口遮挡或关闭到托盘后，客户端应继续接收 Chrome 插件心跳、验证业务网站并按原周期采集指标。电脑必须保持唤醒，Chrome 和桥接插件必须运行，业务平台登录必须有效。系统休眠、合盖休眠、退出 Chrome 或网络中断不属于可持续采集的条件。

## 2026-10-25 排查依据

测试实例的日志显示，18:09:03 投递的 `dji-tasks` 在 18:09:36 超时，此后多个平台验证请求未投递便超时；18:12:18–18:12:23 三个平台验证又陆续完成。期间 `app.pulse` 仍按分钟记录，说明原生后台观察器没有整体停转。18:13:14 又出现任务同步占住浏览器执行队列、后续验证超时的情况。

代码中的页面 Promise 没有插件侧的截止时间。司空任务读取包含页面内的 50 ms 提示框等待，隐藏页面节流时该等待可能大幅延迟；客户端侧超时不会自动结束插件内的等待。因此，心跳仍续租并不代表队列还能处理新的探测。这是本次修复的明确缺口，日志本身不能单独证明每次停顿都由系统节流导致。

## 实现

- Windows、macOS 共用的 Chrome 读取路径：网站验证、江苏指标、司空任务和航线、天气、报告采集在读取期间使用 CDP 的页面焦点模拟，不切换标签页、不把 Chrome 窗口拉到前台；完成或失败后恢复默认状态。
- 插件 Service Worker 独立计时：普通读取最多 25 秒，网站验证和天气读取最多 20 秒，较长的指标与报告读取最多 80 秒；焦点设置与恢复分别最多 2 秒。失败会返回真实错误并允许队列继续，迟到结果不再上报。该包装器仅用于读取，不用于计划填写或提交，也不重放过期任务。
- 插件原有的 5 秒心跳、30 秒 Chrome alarm 兜底，以及忙碌时只续租、不领取更多任务的行为继续使用。原生 75 秒心跳租约和网站验证有效期没有放宽。
- macOS 在客户端运行期间持有 `NSProcessInfo` 用户活动令牌，防止 App Nap 延后原生任务，退出时释放。使用允许空闲系统休眠的选项，不阻止屏幕关闭或用户休眠。
- 主窗口配置 `backgroundThrottling: disabled`，用于支持该配置的 macOS 14+；该选项不支持 Windows。Windows 的平台验证和定时采集仍由原生 Rust 任务执行，插件侧修复同样适用。
- 窗口恢复可见或获得焦点时立即读取原生状态，不必等界面轮询定时器恢复。
- 插件及最低兼容版本为 **0.7.23**，旧插件会明确提示更新；`app.background_policy` 日志记录原生调度、App Nap 和系统休眠策略。

## 验收

自动化覆盖：隐藏页面执行前后的焦点策略、读取失败清理、冻结页面超时、迟到回执忽略、心跳续租后继续下一探测，以及窗口恢复的立即刷新。另运行扩展回归、Rust 单元测试和前端构建。

实机需要在更新客户端、重新加载 0.7.23 插件后分别验证 Windows 与 macOS：

1. 保持电脑唤醒、Chrome 运行并完成业务登录；确认监测已开始。
2. 将客户端最小化或关闭到托盘，Chrome 切换到无关页面；持续 10–15 分钟以上，至少跨过两个指标同步周期。
3. 从日志核对 `job.delivered` / `job.finished`、指标同步成功和最后成功时间，确认后台验证与采集完成；仅有 `app.pulse` 或端口存活不算业务验收。
4. 恢复窗口，核对状态立即更新；断网、登录失效应正常显示异常，不能显示虚假通过。

## 本机 macOS 观测结果

2026-10-25（北京时间），用户重新加载插件后，日志于 **19:40:39** 确认接入 **0.7.23**。用户将客户端转入后台，观测区间为 **19:42:36–19:53:27**，持续约 **10 分 51 秒**，跨越两个完整的指标同步间隔。

- 窗口状态始终为 `visible=false`、`focused=false`、`minimized=false`，本轮实际覆盖的是窗口隐藏/托盘后台运行。11 条分钟存活记录均处于该状态，监测就绪；没有插件断连、三个网站状态降级或超过 90 秒的后台观测空档。
- 平台验证 **36 次成功**（江苏 12 次、司空与可飞合计 24 次），司空任务读取 **7 次成功**，天气读取 **2 次成功**，以上任务均无失败或超时。司空任务读取最大总耗时约 6 秒。
- 指标同步 **3 次成功落库**：19:42:53（50 行）、19:48:13（49 行）、19:53:18（49 行）。SQLite 中 `last_success` 与最后落库时间一致；最新小时观测为 19:00。行数为每次读取并合并的范围，不能相加当成新增记录数。
- 同期自动报告读取有 **12 次**明确返回“尚无 Immediate-Media 照片文件夹”。这是报告资料未齐，本次没有修复该问题；这些失败均及时返回，没有堵住平台验证、天气或指标同步。
