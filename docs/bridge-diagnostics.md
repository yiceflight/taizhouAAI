# 本机连接诊断

入口：客户端「运行状态」→「本机连接诊断」。进入页面自动检查一次，可点击「重新诊断」，也可「复制诊断结果」交给技术支持。结果标注检测时间，是一次快照；浏览器状态改变后需重新诊断。

| 检测项 | 检测内容 | 失败后的处理 |
| --- | --- | --- |
| 随 App 附带的插件目录 | 解析真实安装位置，检查 manifest 存在及后台入口、桥接配置文件可读取 | 检查目录移动、文件缺失或隔离记录；不能据此断言 Chrome 加载了该目录 |
| 本机端口 | 原生 TCP connect，超时 2 秒；正式版 127.0.0.1:14520，开发版 127.0.0.1:14521 | 展示原始系统错误；检查本机服务启动错误和安全软件记录，不能仅凭失败认定防火墙拦截 |
| 当前客户端服务 | TCP 成功后发起只读 /diagnose 请求，核对本次进程的实例 ID | 端口通但身份不符、HTTP 异常或请求超时，提示检查旧客户端、重复实例或其他占用 |
| 客户端服务错误 | 若后台监听启动或运行失败，展示实际错误 | 根据错误处理端口占用或访问权限，处理后重启；诊断本身不会重启服务 |
| 浏览器插件心跳 | 读取当前有效会话及版本 | 区分无心跳、版本过低、多个会话；给出 Chrome 扩展管理页处理建议 |

诊断不启动 PowerShell，不要求管理员权限；使用原生 TCP 和 HTTP 请求，支持 Windows 与 macOS。HTTP 探测禁用代理和重定向，限制超时及回执大小；接口沿用桥接的 Origin、Host 和请求头校验。该请求不伪造浏览器心跳，不领取任务，不影响登录验证或飞行任务。

App 内 TCP/HTTP 通过，只说明 App 能访问自身服务，不代表 Chrome 的请求一定可达。没有收到心跳时，无法从 App 直接区分插件未安装、未启用、后台启动失败、加载了其他目录或浏览器请求被拦截；需要检查扩展 ID、版本以及 Chrome 错误信息。连接信息中显示预期插件 ID、最低版本、渠道和端口供核对。

复制结果包含客户端版本、系统、检测时间、本机安装目录及错误建议，不包含浏览器标签页、账号或令牌。仅复制到剪贴板，不自动上传。

验证：Rust 真实临时 TCP 服务覆盖端口不通、正确实例、其他实例、异常回执、HTTP 拒绝、重定向及超时；接口授权与无心跳副作用测试；UI 覆盖自动检查、防重复、失败重试、清除旧结果及复制。Windows 实机安装后的诊断回读仍需单独验收。
