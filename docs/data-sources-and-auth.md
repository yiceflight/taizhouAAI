### 异常触发与巡查流程

- K 离子浓度 **> 1 μg/m³**。
- PM2.5 浓度 **> 60 μg/m³**。
- 根据风向、风速，向下风向开始无人机巡飞。
- 巡查火点、工地、裸土、扬尘、河道等目标，结合可飞多参数数据形成高值巡查报告。

“超过”按严格大于记录，等于阈值不属于超过。原始要求尚未说明两项阈值之间是“任一满足”还是“同时满足”，本次不替用户确定 AND/OR，也不启用自动起飞。站点范围、采样周期、持续超标时长、异常值质量控制、重复告警间隔、巡飞距离及报告指标口径待业务实施时明确。

风向字段的来向/去向定义和风速单位必须以平台字段说明为准；若使用气象来向，下风向为 `(风向 + 180°) % 360°`。缺测或静风时不能直接生成有效巡飞方向。

Cookie/token 的保存与服务器续期是两件事。检查接口能判断当前是否仍登录，不代表调用它能延长会话；服务器注销、撤销、绝对到期、风控或验证码要求都可能使会话失效。

## 3. 可飞：已实测的密码登录与会话复用

2026-09-21 从平台公开前端代码核对并调用以下接口：

- API 根地址：`https://api-aai.airins.cn/api/mets/total`。
- 登录：`POST /account/user/login/pwd`，JSON 字段为 `account`、`password`。
- 登录态检查：`GET /account/user/i/s/account`。
- 前端以 `withCredentials: true` / `credentials: "include"` 携带 Cookie；业务 HTTP/JSON 状态为 401 时清理页面存储并跳转登录页。

实测结果：

1. 空 Cookie 会话检查返回 HTTP 200、`isSuccess: false`，因此不能仅以 HTTP 200 判断已登录。
2. 使用用户提供的账号密码登录，返回 HTTP 200、`isSuccess: true`。
3. 登录后的检查返回 `isSuccess: true`。
4. 返回一个名为 `token` 的 Cookie，Domain 为 `.airins.cn`，带 Secure、HttpOnly 属性。本次观察到的到期时间为 **2026-09-22 23:05:54 +08:00**；这只是该次会话的声明到期时间，服务端可能提前撤销。
5. Cookie 已保存到 `.secrets/airins-cookies.txt`，新的 Python 进程从文件加载后检查通过。未输出 Cookie 值、登录响应正文或账号详情。
6. Chrome 原有页面刷新后重新加载出历史记录，证明浏览器当前会话可用；这不等于验证浏览器重启后的恢复。
7. 另一独立进程使用保存的 Cookie 调用只读 `GET /account/detail`，返回 `isSuccess: true`、业务状态 `200` 和非空数据；随后再次检查登录态成功，Cookie 到期时间未变化。因此本次没有获得“调用检查接口可以续期”的证据。

目前检查的前端资源未发现 refresh token 流程。此结论限于本次已下载代码，不能据此断言服务器不支持其他续期方式。

### 本机复用工具

```bash
# 默认只检查现有会话，输出结果和 Cookie 到期时间，不打印凭据。
python3 scripts/airins-session.py check

# 手动启动密码登录，交互输入账号和密码，密码不进入命令行参数。
python3 scripts/airins-session.py login
```

退出码：`0` 表示登录态检查通过，`1` 表示未登录或登录被拒，`2` 表示网络、响应或会话文件错误，不能当作密码错误。成功检查后会保存服务器返回的 Cookie 更新；工具不定时运行、不自动重试密码、不假设每次检查都会续期。该工具是本机接入验证工具，尚未接入桌面客户端的自动登录 UI 或后台任务。

## 4. 大疆司空：优先正式 API 接入

[大疆官方公有云 OpenAPI V2.0 文档](https://fh.dji.com/user-manual/en/custom-development/open-api/public-cloud-v2.html)说明了组织、设备、飞行任务、直播等接入能力；认证使用 `X-User-Token`，项目级接口还需要 `X-Project-Uuid`。[官方示例仓库](https://github.com/dji-sdk/FlightHub-2-OpenAPI-V2-Demo/blob/main/README.en.md)说明组织设置中的 OpenAPI Key 获取方式。

OpenAPI Key 与短信登录后的网页会话凭据应分开管理。尚未检查该组织是否已开通相关权限，不能把“文档提供此能力”当作“当前账号已能操作机库”。网页短信登录可以复用尚有效的会话，但失效后可能仍需人工接收验证码，不能承诺永久免验证。具体巡飞、机库控制和识别功能需逐项匹配可用 API 与设备能力。

## 6. 与现有客户端的关系和后续实现

`src/config/sites.ts` 已配置三个业务网站，但展示名称为“综合地图 / DJI FlightHub / 历史云台”，可飞当前打开 `HistoryCloud`，用户本次指定的是 `Realtime`。本次只记录入口差异，没有改动现有页面导航。

现有 Chrome 插件只报告标签页并采集页面正文与 HTML 表格，不读取 Cookie、浏览器存储或输入框值。它显示“已打开”不代表已登录，也没有现成的 token 保管或续期功能。

建议后续按平台建立明确状态：未登录 → 登录中 → 已验证 → 即将到期 → 需要密码重登/人工验证码；网络失败单独显示。客户端集成时采用系统凭据库保存密码、Cookie 或 API Key，页面和报告仅显示登录状态、验证时间、声明到期时间与错误类别。后台只调用经核实的只读检查接口；没有刷新协议时，到期后按平台正常登录流程处理。

需分别验收：有效会话复用、过期 Cookie、401/403、HTTP 200 但业务未登录、网络超时、服务端撤销、客户端/浏览器重启、验证码介入和多进程登录冲突。本次没有启用长期保活任务，没有进行机库或飞行操作。
