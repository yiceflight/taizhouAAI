# 第二步：钾离子超标后准备司空计划

> 下文记录早期 v0.4.0 仅填写行为。v0.7.0 已增加独立提交路径，当前策略见 [无人机调度](drone-dispatch.md)。

2026-09-23。关闭人工确认后的自动巡飞会打开页面、选择航线/机场并填写表单；回读通过后在司空页面右侧显示核对面板并等待 30 秒，期间可取消。倒计时结束后才点击最终「确定」一次。人工确认模式和填写演练仍只停在最终确认前，不自动点击。

## 触发与去重

- 成功同步江苏大气站小时数据后，检查最新一条观测的 K⁺；严格大于 **1.0 μg/m³** 才触发，等于 1.0 不触发。PM2.5 本阶段不参与判断。
- 只接受距当前北京时间不超过 3 小时且非未来的最新小时；K⁺ 缺测、过期或导入失败不触发，不回放历史超标记录。
- 一次连续超标只准备一次。正常有效值（≤ 1.0）重新允许下一次超标触发，缺测不重置。已处理小时持久去重，客户端重启和重复同步不重复准备。
- 有尚未结束的填写任务时保留当前任务；失败不自动重试。先检查 Chrome 草稿，再使用「重试填写」；「结束本次处理」只结束客户端待办，不提交或删除网页草稿。
- 原生后台执行，关闭主窗口后仍工作；完全退出或暂停小时同步后不再产生自动触发。

这一步使用视频中的固定东南航线，尚未接入实时风向选线。指定航线/设备缺失或出现重名时停止，不选择第一条或替代设备。

司空在选择航线时会自动生成航线副本，详见[大疆官方普通计划说明](https://fh.dji.com/user-manual/cn/task-plan-library/single-dock-plan-library.html)。副本后缀不作为航线身份；准备和提交均按配置的名称前缀核对。选择操作仅在「航线库」范围内定位，页面预览标题不作为候选项；多个不同后缀但同前缀的候选项仍按歧义处理。此规则核对名称，不验证航点或航线 ID。

## 桥接与边界

需 v0.4.0 Chrome 插件，保留一个在线桥接会话，并提前完成司空登录。插件为每次处理创建独立标签页，重试复用该标签，不覆盖用户其他页面。用户关闭原草稿页后重试可重新打开；登录跳转或项目变化时停止。

客户端只下发固定 `dji-prepare` 任务、事件 ID、计划名和 `submit:false`，无任意脚本或选择器参数。填写阶段禁止触发最终确认、提交、保存、起飞类控件和 `type=submit`；完成后读取名称、航线、设备、选项、开关、返航高度和告警人员核对。自动提交模式的右侧面板逐项标绿，取消会调用客户端取消接口；30 秒后客户端才下发独立 `dji-submit`，提交阶段再次核对并只点击唯一最终确定按钮。网页升级造成不能定位或不能确认状态时按失败处理。

「已填写」表示最近一次核对时页面保持未提交，并不监控用户之后对草稿的修改、关闭或手动提交。中断中的任务重启后显示失败并要求检查，不能把中断当成功。
