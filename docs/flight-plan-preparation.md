# 第二步：钾离子超标后准备司空计划

> 下文记录早期 v0.4.0 仅填写行为。v0.7.0 已增加独立提交路径，当前策略见 [无人机调度](drone-dispatch.md)。

2026-09-23。关闭人工确认后的自动巡飞会打开页面、选择航线/机场并填写表单；回读通过后在司空页面右侧显示核对面板并等待 30 秒，期间可取消。倒计时结束后才点击最终「确定」一次。人工确认模式和填写演练仍只停在最终确认前，不自动点击。

## 触发与去重

- 成功同步江苏大气站小时数据后，检查最新一条至少有一项有效值的观测；K⁺ 严格大于 **1.0 μg/m³** 或 PM2.5 严格大于 **30 μg/m³** 才触发，等于阈值不触发。
- 只接受距当前北京时间不超过 3 小时且非未来的最新小时；K⁺ 与 PM2.5 均缺测、过期或导入失败不触发，不回放历史超标记录。
- 当前版本按来源小时独立判断，连续超标的新小时可再次触发；同小时持久去重，重启和重复同步不重复准备。具体门控和恢复行为见[无人机调度](drone-dispatch.md)。
- 有尚未结束或结果不明的任务时保留当前任务；提交前准备失败同小时不重试，新有效小时可重新判断。明确天气阻飞不阻塞新小时；结果不明持续核查，不重复提交。
- 原生后台执行，关闭主窗口后仍工作；完全退出或暂停小时同步后不再产生自动触发。

## 视频填写规则

视频的 `新建计划30` 是平台默认序号，不作为重复使用的固定名称。设备卡上的「每日5时东南侧火点巡飞」是已有待执行任务信息，不作为本次计划名称或定时策略。

航线候选从司空项目只读同步到本机。必须在监测设置中同步并选择默认航线。有风向规则时，起飞前读取已复核的司空预报风向，按八方位中文规则优先选择航线；有效风向未匹配规则，或风向缺测、过期、无效时使用设置中的默认航线，规则为空时直接使用默认航线，不要求风向数据。当前任务确定的航线随任务填写传入扩展，准备和提交阶段沿用同一条航线。指定航线/设备缺失、默认航线无效或出现重名时停止，不选择第一条或替代设备；未满足航线配置时准备和提交都会停止，不再使用内置默认航线。

司空在选择航线时会自动生成航线副本，详见[大疆官方普通计划说明](https://fh.dji.com/user-manual/cn/task-plan-library/single-dock-plan-library.html)。副本后缀不作为航线身份；准备和提交均按配置的名称前缀核对。选择操作仅在「航线库」范围内定位，页面预览标题不作为候选项；候选去掉空白后，优先选择精确名称，否则选择与指定前缀字符数差异最小的一条；最小差异并列（包括精确重名）时按歧义停止。后台同步恢复及风向规则允许双向前缀，页面航线库按指定名称的前缀查找；已选表单仍要求唯一。此规则核对名称，不验证航点或航线 ID。

## 桥接与边界

当前需 v0.7.31 或更新的 Chrome 插件（支持 PM2.5 任务名与最小差异选线），保留一个在线桥接会话，并提前完成司空登录。插件为每次处理创建独立标签页，重试复用该标签，不覆盖用户其他页面。用户关闭原草稿页后重试可重新打开；登录跳转或项目变化时停止。

客户端只下发固定 `dji-prepare` 任务、事件 ID、计划名、所选航线前缀和 `submit:false`，无任意脚本或选择器参数。填写阶段禁止触发最终确认、提交、保存、起飞类控件和 `type=submit`；完成后读取名称、航线、设备、选项、开关和返航高度核对。自动提交模式的右侧面板逐项标绿，取消会调用客户端取消接口；30 秒后客户端才下发独立 `dji-submit`，提交阶段再次核对并只点击唯一最终确定按钮。网页升级造成不能定位或不能确认状态时按失败处理。

「已填写」表示最近一次核对时页面保持未提交，并不监控用户之后对草稿的修改、关闭或手动提交。中断中的任务重启后显示失败并要求检查，不能把中断当成功。
