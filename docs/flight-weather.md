# 机场天气与巡查条件

参考 fathom 太湖蓝藻应用 `FlightWeatherWidget.tsx` / `weatherFormat.ts`，由 Tauri 后端调用 Open-Meteo forecast API，无需浏览器插件或 API key。

- 查询点：泰州环境监测 Dock 3，用户提供经度 **119.92992**、纬度 **32.434525**。
- 请求 `current` 温度、天气码、10 米风速、10 米阵风、风向、降水，显式使用 m/s、mm 和 Unix 时间。
- 启动时及每 5 分钟刷新；并发请求复用当次获取结果，15 秒超时。手动刷新、手动起飞/演练、倒计时结束准备计划前、填写完成后正式提交前重新获取。
- 数据时刻超过 30 分钟、获取时间超过 10 分钟、未来时间异常、单位错误、关键字段缺失、接口失败均不放行。旧值只供查看，不沿用通过结论。
- 有降水（包括微量降水、毛毛雨、冻雨）、雪、雷暴不通过；雾需现场复核。风速或阵风 ≥ 7 m/s 且 < 12 m/s 需人工确认和现场复核，暂停自动准备；风速或阵风 ≥ 12 m/s 禁止起飞，人工确认不能覆盖。仅无降水、已知天气码且风速/阵风均 < 7 m/s 通过。阈值是本系统保守业务规则，不是机型认证抗风能力。
- 自动超标判断先更新天气；未通过不创建事件、不消耗超标去重标记。下次监测同步时重新判断，仍须满足现有监测数据新鲜度和超标规则。正常监测读数即使天气不佳也会重新启用下一轮超标判断。
- 已创建的自动任务在倒计时结束和提交前再次复核天气；未通过则标记为起飞准备失败，未发送起飞请求，不会等待天气好转后自动重试。本轮连续超标仍保留去重标记。需要重新执行时，可从顶部入口确认重新发起新的手动任务，无需先归档失败提醒。下一轮自动触发须先出现正常读数，再重新超标，并满足其他门控条件。
- 人工完成现场天气与设备复核后，可以使用“手动强制起飞”弹窗，勾选并确认后为本次手动任务覆盖系统天气判断（包括需复核、缺测或过期，但不覆盖风速或阵风 ≥ 12 m/s 的禁飞限制）。后台在准备和提交前重新获取天气并检查 12 m/s 禁飞限制，记录确认时间；该确认仅作用于当前手动任务的准备与提交，不改变后续自动任务、填写演练或下一次手动任务的门控。已有已提交、结果待核查或执行中任务仍阻止发起新任务。
- 巡查列表以浅绿色整行背景和左侧绿色标记区分本应用任务；天气拒绝的本地事件显示“天气不适飞 · 未起飞”“未起飞 · 不自动重试”，触发数据时间不作为飞行时间显示。
- UI 同时显示机场天气、阻断原因、数据/获取时间及来源，前端还独立检查过期时间。普通手动起飞与自动倒计时提交路径均在后端检查天气；仅明确记录现场复核确认的本次手动任务覆盖天气门控。已有任务仍可前往司空查看。无法阻止操作者直接在司空中的行为。

Open-Meteo 是模型天气，非机场现场实测。当前中国区域数据按服务模型生成，不能替代现场气象与设备检查。服务说明及字段定义：https://open-meteo.com/en/docs

巡查任务的历史天气另从 Open-Meteo Historical Forecast API 读取：`https://open-meteo.com/en/docs/historical-forecast-api`。以可飞任务的北京时间起飞小时为准，验证返回的时区、Unix 时间和单位后保存快照；已保存的快照离线也可查看。它是事后补录的模型小时资料，不是起飞当时保存的现场观测，也不能倒推当时的放飞审批结论。

本应用的任务只在创建时把当时天气写入本地事件 `weatherChecks`，每个新任务仅保存一条 `creation` 快照。保存创建时刻、数据/获取时刻、温度、天气现象、风速、阵风、降水、来源及当时判断原因；获取失败、缺测和过期也保留，旧值仅供查看。起飞准备和提交前仍重新获取并检查天气，但不追加或覆盖任务天气；准备/提交异常、执飞异常和暂停核查也不追加天气记录。重新发起的任务保存自己的创建快照，原任务记录保留。任务列表只显示创建时天气，下方直接按行展示“任务创建时刻”和“天气数据时刻”，每项独占一行；天气数据缺失时标记“未获取”，不再显示详情展开项、获取时刻、来源或记录条数；兼容旧任务的多阶段记录时只选取 `creation` 快照，不删除历史数据。本地记录关联到唯一同名平台任务后仍保留；没有创建快照时显示“当时天气未记录”，不使用后续检查或当前天气代替。创建快照来自当时缓存的模型资料，不代表现场实测或已批准起飞。

验证：`cargo test --manifest-path src-tauri/Cargo.toml`；真实 API 只读检查 `cargo test --manifest-path src-tauri/Cargo.toml weather::tests::live_weather -- --ignored --nocapture`。
