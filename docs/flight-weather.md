# 机场天气与巡查条件

参考 fathom 太湖蓝藻应用 `FlightWeatherWidget.tsx` / `weatherFormat.ts`，由 Tauri 后端调用 Open-Meteo forecast API，无需浏览器插件或 API key。

- 查询点：泰州环境监测 Dock 3，用户提供经度 **119.92992**、纬度 **32.434525**。
- 请求 `current` 温度、天气码、10 米风速、10 米阵风、风向、降水，显式使用 m/s、mm 和 Unix 时间。
- 启动时及每 5 分钟刷新；并发请求复用当次获取结果，15 秒超时。手动刷新、手动起飞/演练、倒计时结束准备计划前、填写完成后正式提交前重新获取。
- 数据时刻超过 30 分钟、获取时间超过 10 分钟、未来时间异常、单位错误、关键字段缺失、接口失败均不放行。旧值只供查看，不沿用通过结论。
- 有降水（包括微量降水、毛毛雨、冻雨）、雪、雷暴不通过；雾需现场复核。风速或阵风 > 6 m/s 需现场复核且暂停准备，> 10 m/s 不宜起飞。仅无降水、已知天气码且风速/阵风均 ≤ 6 m/s 通过。阈值是本系统保守业务规则，不是机型认证抗风能力。
- 自动超标判断先更新天气；未通过不创建事件、不消耗超标去重标记。下次监测同步时重新判断，仍须满足现有监测数据新鲜度和超标规则。正常监测读数即使天气不佳也会重新启用下一轮超标判断。
- UI 同时显示机场天气、阻断原因、数据/获取时间及来源，前端还独立检查过期时间。手动起飞与自动倒计时提交路径均在后端检查天气，已有任务仍可前往司空查看。无法阻止操作者直接在司空中的行为。

Open-Meteo 是模型天气，非机场现场实测。当前中国区域数据按服务模型生成，不能替代现场气象与设备检查。服务说明及字段定义：https://open-meteo.com/en/docs

验证：`cargo test --manifest-path src-tauri/Cargo.toml`；真实 API 只读检查 `cargo test --manifest-path src-tauri/Cargo.toml weather::tests::live_weather -- --ignored --nocapture`。
