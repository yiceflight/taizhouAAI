# 司空气象接入

机场天气来自大疆司空 2，取代 Open-Meteo。使用已有 Chrome 登录会话和满足 `bridge-config.json` 最低版本要求的桥接扩展，凭据仅留在司空页面内，不传回客户端、不保存到任务记录。

- 固定泰州项目 `c7ea6bbc-110d-4dc9-ac75-4653ebbbca49`、机场 `AHRXNBN00A029A`（泰州环境监测 DJI Dock 3）。先通过只读 `GET /manage/api/v1/projects/{projectId}/topologies` 验证归属、机型和在线状态。
- 预报使用 `POST /manage/api/v1/common/weather-report/v2` 只读查询，坐标来自机场遥测。请求固定中国区 HTTPS API，禁止携带凭据重定向。预报气温、湿度、天气现象与降水来自 JSON；机场风速、降雨等级、环境温度及时间来自司空已解码的 WebSocket OSD 数据。降雨等级不冒充毫米降水量，缺失的阵风不填零。
- 司空接口本身不返回适飞结论。按选定方案，读取已挂载 `WeatherFullDisplay` 组件的 `airworthy`、`getTipByAirworthy` 和项目气象条目结果。不读取 DOM 正文，不解析显示文字为数字，也不复制司空气象阈值、天气码或项目配置判断规则。DOM 仅用于定位 Vue 根节点；不依赖 Webpack 模块编号。
- 映射司空等级：1 为适合飞行，2 为不宜飞行，3 为无法飞行，仅用于展示和任务天气快照。App 不根据天气结论、缺测、过期或读取失败阻止自动/手动任务、填表或提交，也不要求天气覆盖确认；是否允许起飞由大疆后台决定。有效预报风向用于选线；读取失败或风向缺测、过期、无效时使用默认航线并保留错误原因。禁飞时段、平台登录、任务去重和未完成任务保护仍然生效。
- 成功后每 5 分钟更新；启动或登录失败每 30 秒重试，电脑从锁定或休眠恢复时立即强制重查一次，准备选线前更新天气；准备阶段仅复用 15 秒内刚成功校验且遥测仍新鲜的回执，失败回执不复用，提交前不再以天气判断是否放行；提交沿用已填写的航线。扩展复用自己创建的后台 team 标签页并刷新，避免司空组件沿用旧预报；不导航或刷新用户原有标签页。通过 CDP 临时启用后台焦点模拟使组件初始化，读取后恢复，不切换用户当前标签页。
- 首次接收要求遥测在 2 分钟内、预报覆盖当前小时；客户端展示缓存最多 30 分钟（实测时间额外容纳接收时允许的 2 分钟延迟）；准备选线只复用 15 秒内成功校验的回执。接口或组件失败立即标为未知，旧数值仅供查看；失败原因保留在天气视图及任务创建快照中，风向选线不使用失败回执。客户端与页面时间异常同样拒绝。
- 组件名或字段在司空升级后变化时会显示适配器未就绪，不回退抓页面文字、不回退自有规则。此组件契约不是 DJI 承诺稳定的公开 API，后续可能需要更新桥接扩展。

任务仍只保留创建时的一条 `creation` 天气快照。保存实测时间、预报时间、获取时间、司空原始等级/结论、气象条目与来源。准备及提交前的重查不追加、不改写历史。手动新建和重试在保存创建快照前刷新天气。

已有 Open-Meteo 历史记录继续可读；停止向 Open-Meteo 补录。司空当前天气不能证明历史任务当时的气象，未保存创建快照的任务显示“当时天气未记录”。

验证命令：`npm test`、`npm run test:ui`、`npm run build`、`cargo test --manifest-path src-tauri/Cargo.toml --lib`。上线还应使用已登录 Chrome 和重载后的插件验证真实回执，并在原生客户端检查显示及刷新；无需触发实际飞行。

2026-10-13 本机验收：开发扩展 v0.7.15 已重新加载，原生客户端完整刷新成功。20:21 回执为机场实测风速 0 m/s、环境温度 21.7°C、无降雨；司空预测飞行风速 14.9 m/s、预报 20°C，平台结论“无法飞行”。验证未触发飞行，也未发布正式安装包。

2026-10-13 调度修复：v0.7.18 扩展每次只领取一个任务，完成后立即重新请求调度；天气和飞行状态优先于历史补读和报告素材。正在执行的任务不强制中断。历史补读每批 2 页，完整扫描成功落库后 6 小时再扫描；最新页仍按原来的周期同步。组件未就绪错误分别说明设备卡片、气象条目、实时在线状态或遥测时间，不再直接提示更新适配器。


2026-10-27 风向接入：v0.7.30 插件从当前有效预报记录读取数值 `wind360` 为 `windDirection`；0°/360° 对应北风，缺失或异常值返回 null，不从 `windDir` 文本、机场风速或更早的预报补猜。未配置风向规则时直接使用默认航线；配置规则后，缺少有效风向或该风向未配置航线时也使用默认航线。客户端保存的天气快照同时包含风向角度和对应的预报时刻；天气详情以八方位中文显示，并明确标为“预报风向”。风向匹配及区间边界见 `monitoring-settings.md`。

2026-10-31 超时预算修复：天气页面读取单独使用 50 秒上限，覆盖两次各 12 秒的接口请求及最多 20 秒的组件等待；客户端天气任务为 85 秒，包含页面加载与桥接清理。站点检查仍为原有预算。插件及最低版本同步为 0.7.37；真实运行版本与重载验收需单独核实。

2026-10-31 天气用途调整：天气只用于任务记录、展示和风向选线。自动与手动任务均将起飞判定交给大疆后台；司空明确阻飞回执仍保留，不自动点击后续确认，也不重复提交同一任务。历史记录里的 weatherOverrideConfirmedAt 字段继续可读，不再参与天气放行。
