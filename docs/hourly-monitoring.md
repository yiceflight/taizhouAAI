# 江苏大气站小时同步

## 范围与口径

- 网站：`http://61.155.4.60:18080/`，已登录的地图等页面均可，不要求切换到时间序列页。
- 泰州市 `321200`，城市 `CITY`，小时 `HOUR`，混合数据 `A_6`。
- K⁺ 从该城市离子色谱（IC）组分列表按名称唯一识别，不硬编码因子号；要求单位为 μg/m³。
- 同时采集泰州市城市口径的 K⁺ 与 PM2.5 小时数据。PM2.5 用于监测表格和趋势图；可飞巡飞采样仍单独用于报告。
- 使用来源数据时间（北京时间 UTC+8），按 K⁺ 来源时间轴保存小时值。

## 工作方式

客户端原生后台每 5 分钟向满足 `bridge-config.json` 最低版本要求的 Chrome 桥接插件下发专用任务，插件复用已登录网站的全局 `$Ajax` API 客户端，直接请求指标目录和 K⁺ 小时数据。不读取或传出密码、Cookie、token，不改变用户页面筛选条件。默认启用，支持暂停和按图表时间范围立即补齐。需保持客户端和 Chrome 运行；用户只需完成网站登录，停留在地图页即可。验证检查已有的同源标签页，旧登录页或失败的时间序列页不会遮蔽另一个已登录页面；同步绑定本次通过 API 验证的标签页。没有网站标签页时才在后台打开地图入口，不因缺少某个业务组件创建新页面。登录过期后提示重新登录，暂未做密码自动重登。

首次查询当前北京时间整点之前 7 天；成功后保存查询截止时间，下一轮回查 48 小时，以补录迟到数据及更新修订值。已写入的有效浓度不会被后续响应中的空值覆盖，因此大气站延迟产出后，下一轮回查会补回原小时。图表刷新按当前选择的今天、24 小时、3 天或 7 天计算动态起止时间，整段 upsert 以补齐其中缺口，不依赖“已启动监测”状态。长时间离线时按最大 7 天窗口向前补齐，每轮前进最多 5 天。超过回查区间的历史修订不会自动重扫。调度周期约为每轮完成后 5 分钟，非平台推送。江苏大气站和插件就绪即可启动、同步；司空或可飞异常不阻塞 K⁺ 采集。首页指标和巡查判断使用最近一条有有效 K⁺ 的小时记录，尾部暂时缺测的小时仍保留在图表和表格中。自动起飞事件保存来源小时并按小时去重；手动起飞可以与同一来源小时建立多条记录。

采集字段依据 2026-09-22 实际下载的平台前端：`index.38e10a6d.js` 与 `chunk-5e1669da.2c10a563.js`。

- `componentDeviceOption`：组分列表。
- `photoTimeSeriesData`：K⁺ 的 `factorCode / dataTimes / values`。
- `getNormalSixParamData`：按 `dataTime / pm25` 返回 PM2.5 小时序列，与 K⁺ 按来源小时对齐。

通过 Vue 根实例的全局 `$Ajax` 查找 API 客户端，不依赖 `PM-time-series` 组件。网站升级或响应结构不符时明确报错，不改用正文推测浓度。查询仅返回所需监测值及口径，不返回完整平台响应或身份信息。

## 数据持久化

Tauri 应用数据目录中的 `monitoring.sqlite3`，SQLite WAL 模式。

`hourly_observations`：城市代码 + 小时为主键，保存 potassium、pm25、单位、来源 URL、数据口径及同步时间。旧数据库继续兼容已有 pm25 列；新同步同时更新两项指标，缺测写入 NULL。事务内 upsert，同时推进成功游标。拒绝越界/非整点/重复小时、负数/非数浓度、错误来源或单位，整批失败不推进游标。

0 是有效监测值；缺测为 NULL。v0.7.9 起，查询范围内平台已返回的小时全部保存，包括尾部 K⁺ 为空或整批为空的小时。首页按最新来源小时显示时间，K⁺ 为空时显示“暂无数据”，暂不判断巡查触发条件，不回退使用旧小时浓度。图表保留空值小时的位置但不绘制柱子，表格显示“暂无数据”；平台完全未返回的小时不凭空插值。后续回查可将空值更新为平台补报的有效值。首页提示 K⁺ 完整性和相邻记录间缺失小时。
