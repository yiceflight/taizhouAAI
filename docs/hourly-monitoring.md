# 江苏大气站小时同步

## 范围与口径

- 页面：`http://61.155.4.60:18080/#/particle-analysis/feature-analysis/time-series`。
- 泰州市 `321200`，城市 `CITY`，小时 `HOUR`，混合数据 `A_6`。
- K⁺ 从该城市离子色谱（IC）组分列表按名称唯一识别，不硬编码因子号；要求单位为 μg/m³。
- PM2.5 使用城市常规来源 `commonSiteType=30`，与页面当前已选择口径一致，单位 μg/m³。
- 使用来源数据时间（北京时间 UTC+8），分别读取 K⁺ 时间轴与 PM2.5 的 `dataTime` 后按小时连接，不按数组下标拼接。

## 工作方式

客户端原生后台每 5 分钟向 v0.3.0 Chrome 桥接插件下发专用任务，插件在已登录的时间序列页面使用平台自身 API 客户端执行等价查询。不读取或传出密码、Cookie、token，不改变用户页面筛选条件。默认启用，支持暂停和立即同步。需保持客户端、Chrome、该页面运行；登录过期后提示重新登录，暂未做密码自动重登。

首次查询当前北京时间整点之前 7 天；成功后保存查询截止时间，下一轮回查 48 小时，以补录迟到数据及更新修订值。长时间离线时按最大 7 天窗口向前补齐，每轮前进最多 5 天。超过回查区间的历史修订不会自动重扫。调度周期约为每轮完成后 5 分钟，非平台推送。

采集字段依据 2026-09-22 实际下载的平台前端：`index.38e10a6d.js` 与 `chunk-5e1669da.2c10a563.js`。

- `componentDeviceOption`：组分列表。
- `photoTimeSeriesData`：`factorCode / dataTimes / values`。
- `getNormalSixParamData`：`dataTime / pm25`。

页面 Vue 组件名 `PM-time-series`。网站升级或响应结构不符时明确报错，不改用正文推测浓度。查询仅返回所需监测值及口径，不返回完整平台响应或身份信息。

## 数据持久化

Tauri 应用数据目录中的 `monitoring.sqlite3`，SQLite WAL 模式。

`hourly_observations`：城市代码 + 小时为主键，保存 potassium、pm25、单位、来源 URL、数据口径及同步时间。事务内 upsert，同时推进成功游标。拒绝越界/非整点/重复小时、负数/非数浓度、错误来源或单位，整批失败不推进游标。

0 是有效监测值；缺测为 NULL。尾部两项都为空的预留时槽不作为最新观测；区间内缺测保留为空，平台完全未返回的小时不凭空插值。首页提示两项完整性和相邻记录间缺失小时。

## 验证

- `pnpm test`：真实协议形状的测试夹具，覆盖时间轴错位、零值、缺测、尾部空槽、非法数值、重复时间、登录失效、来源范围。
- `cargo test --manifest-path src-tauri/Cargo.toml`：SQLite 幂等更新、重启后读取、非法批次原子拒绝、断线后时间窗口续传。
- `pnpm build`：前端类型检查与构建。

测试夹具不属于真实平台数据。实机联调结论另行记录，不以单元测试代替在线验收。
