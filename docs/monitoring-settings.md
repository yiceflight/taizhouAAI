# 监测设置

工作台导航栏右侧的“设置”打开弹窗。修改后点击“保存设置”写入本机 `monitoring.sqlite3`，重启后保留；取消或 Esc 不保存草稿。“恢复默认”先恢复表单，仍需保存才生效。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 钾离子 K⁺ 阈值 | 1.0 μg/m³ | 大于阈值才视为超标；用于卡片、图表、表格提示与巡查触发 |
| PM2.5 报告阈值 | 60 μg/m³ | 位于无人机设置下方；用于可飞巡飞报告的超阈值统计，不参与江苏大气站监测 |
| 钾离子超标后延迟 | 5 分钟 | 仅在关闭人工确认、自动起飞时显示和生效；可设 0–1440 整数分钟；自动巡飞开启后，从发现有效超标数据时计时；修改用于后续任务 |
| 起飞前人工确认 | 开启 | 自动任务完成计划填写后等待人工确认；关闭后按自动巡飞流程执行 |

“AI 巡查分析”中火点默认显示开启，其余五项显示关闭；当前为固定展示状态，未接入新的 AI 分析执行能力。

浓度阈值须为大于零的有限数值。前端验证输入，Rust 再次验证后原子保存。设置保存在 `monitor_settings.workspace_settings`，监测显示、巡飞与报告模块共同读取；单独修改巡飞延迟也更新该配置。保存配置本身不会创建或提交巡飞任务。

实际巡飞仍受自动巡飞开关、数据有效期、工作环境与天气检查约束；计划提交回执不代表无人机已经起飞。
