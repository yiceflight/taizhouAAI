# 监测设置

工作台导航栏右侧的“设置”打开弹窗。修改后点击“保存设置”写入本机 `monitoring.sqlite3`，重启后保留；取消或 Esc 不保存草稿。“恢复默认”先恢复表单，仍需保存才生效。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 钾离子 K⁺ 阈值 | 1.0 μg/m³ | 大于阈值才视为超标；用于卡片、图表、表格提示与巡查触发 |
| PM2.5 报告阈值 | 60 μg/m³ | 位于无人机设置下方；用于可飞巡飞报告的超阈值统计，不参与江苏大气站监测 |
| 钾离子超标后延迟 | 5 分钟 | 仅在关闭人工确认、自动起飞时显示和生效；可设 0–1440 整数分钟；自动巡飞开启后，从发现有效超标数据时计时；修改用于后续任务 |
| 起飞前人工确认 | 开启 | 自动任务完成计划填写后等待人工确认；关闭后按自动巡飞流程执行 |
| 禁飞时间 | 每天 05:00–08:00（北京时间） | 支持添加、修改、删除多段时间，最多 24 段；结束早于开始时跨午夜；全部删除可取消此限制 |

“AI 巡查分析”中火点默认显示开启，其余五项显示关闭；当前为固定展示状态，未接入新的 AI 分析执行能力。

浓度阈值须为大于零的有限数值。前端验证输入，Rust 再次验证后原子保存。设置保存在 `monitor_settings.workspace_settings`，监测显示、巡飞与报告模块共同读取；单独修改巡飞延迟也更新该配置。保存配置本身不会创建或提交巡飞任务。

实际巡飞仍受自动巡飞开关、数据有效期、工作环境与天气检查约束；计划提交回执不代表无人机已经起飞。

禁飞时段包含开始时间、不包含结束时间。数据所属小时或当前调度时间处于禁飞时段时，有效 K⁺ 超标只保存“禁飞时间”记录，不填写或提交起飞计划。禁飞结束后不补飞这些已记录的小时；新的有效超标小时继续按现有策略判断。后台在倒计时和提交前再次检查当前配置，修改时段也能阻止尚未提交的任务。手动起飞与天气强制起飞同样受当前禁飞时间限制；填写演练不提交。平台已有的定时任务由平台执行，不受本客户端限制影响。

旧配置未包含禁飞字段时按默认 05:00–08:00 读取；明确保存空时段列表后不再限制。顶部只显示简要任务状态，监测卡片下方的“巡查任务”显示人工核验提示、原始回执和最近记录。“填写核对未通过”等回执不等于已经确认电量或设备故障，具体原因由现场人工核验。

保存或删除禁飞时段时，后台在同一事务中重新检查当前禁飞状态；原时段不再适用时，将原记录保留在历史中并解除当前禁飞提醒。保存后界面立即刷新，无需等待下一轮小时同步。已跳过小时的去重标记保留，不因修改设置自动补飞。读取状态也会修复旧版本在时段删除后残留的当前禁飞提醒。

当前状态提示以当前北京时间判断：例如 05:00–08:00 在 08:00 结束后，07:00 的禁飞跳过记录只在历史中显示，不再作为顶部或巡查任务的当前禁飞提醒。最新有效数据仍为该超标小时，则提示“等待新小时数据”，说明不自动补飞、可手动执行；手动执行仍需浏览器、网站和天气等条件通过。
