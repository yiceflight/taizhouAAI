# 0.2.10 正式版

发布日期：2026-11-01。客户端版本：0.2.10；随包及最低兼容插件版本：0.7.40。

## 更新内容

- K⁺ 与 PM2.5 分别使用各自最新、三小时内的数据判断超标，避免较新的正常 PM2.5 数据遮挡延迟到达的 K⁺ 超标数据；任务绑定实际触发指标所属小时，保留按小时防重。
- 监测阈值可只配置一项，留空指标不参与触发；界面分别显示指标时刻、有效性和启用状态。
- 司空任务同步使用专用后台页面，支持页面关闭后恢复、登录跳转重试和等待任务列表加载。
- App 打开的平台页面归入蓝色「泰州监测 · App 托管」标签组，开发版使用独立分组；自动查找不复用用户另行打开的平台页。原有任务保存的页面再次使用时会归组。
- 改善长航线名称的选择菜单；插件就绪后立即补取缺失天气。

## 升级说明

提供 Windows x64、macOS Apple Silicon / Intel 通用安装包及在线更新。升级后需更新并在 Chrome 扩展管理页重新加载随包插件，确认实际运行版本至少为 0.7.40；本次新增标签组权限。仅替换磁盘文件不代表插件已重新加载。
