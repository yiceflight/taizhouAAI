# 0.2.11 正式版

发布日期：2026-11-01。客户端版本：0.2.11；随包及最低兼容插件版本保持 0.7.40。

## 更新内容

- 修复机场天气已有缓存但已过期时未立即补取的问题。插件就绪、天气缺失或判定失效时自动请求刷新；窗口恢复焦点时读取状态后也会触发。
- 已有天气刷新正在进行时不重复请求；一次补取失败后的重试由后台定时器负责，避免状态轮询造成重复请求。
- 司空有效的“不宜飞行”或“无法飞行”结论不触发此补取逻辑；天气仍仅用于展示、记录和有效风向选路，不新增本地起飞拦截。

## 升级说明与验证边界

通过现有正式发布流水线构建 macOS universal 与 Windows x64 安装包，并验证 updater 签名、发布 OSS 在线更新和 GitHub Release。本次未修改插件代码，已运行 0.7.40 插件的用户无需因本次修复重新加载插件。

发布前运行 Node、UI 测试和正式前端构建；两平台 Rust 测试与安装包构建由流水线执行。新增回归测试覆盖缓存过期后立即补取、重复请求抑制、恢复后再次失效，以及已有刷新和有效不适飞结论。

未执行真实无人机起飞、Windows 真机安装升级或正式客户端实际 OTA 验收。现有流水线未配置 macOS Developer ID 签名/公证或 Windows Authenticode 签名；updater 签名不等同于操作系统代码签名。
