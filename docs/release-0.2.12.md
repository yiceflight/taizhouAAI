# 0.2.12 正式版

发布日期：2026-11-01。客户端版本：0.2.12；随包及最低兼容插件版本：0.7.41。

## 更新内容

- 读取司空气象前，识别并展开折叠的“机场/地面站”分组，再等待设备卡片、打开机场详情，避免分组折叠和延迟加载造成持续等待。已展开的分组不重复点击，气象数据仍来自平台组件和接口。
- 没有历史天气数据时显示实际取数失败原因，不再一律覆盖为“暂无天气数据，将自动获取”。
- 保留 0.2.11 的气象失效后立即补取逻辑，以及后台失败重试和重复请求抑制。

## 升级说明

提供 macOS Apple Silicon / Intel 通用版与 Windows x64 安装包及在线更新。升级客户端后，请在 Chrome 扩展管理页重新加载随包插件，确认实际运行版本为 0.7.41 或以上。磁盘插件文件更新不代表 Chrome 已加载新代码，客户端会拦截旧插件。

## 验证边界

发布前执行 Node、UI 测试及正式前端构建；流水线执行双平台 Rust 测试、安装包构建、updater 签名校验及 OSS 发布验证。回归用例覆盖折叠分组延迟加载、已展开分组不被折叠和失败原因展示。

真实排查曾记录机场卡片未就绪、页面加载超时，也曾成功取得天气；本次补齐分组展开步骤，不据此宣称所有取数失败均已解决。新插件持续自动取数、正式客户端实际 OTA 和 Windows 真机安装升级仍需现场验收。

现有流水线未配置 macOS Developer ID 签名/公证或 Windows Authenticode 签名；updater 签名不等同于操作系统代码签名。
