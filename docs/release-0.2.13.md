# 0.2.13 正式版

发布日期：2026-11-01。客户端版本：0.2.13；随包及最低兼容插件版本：0.7.41。

## 更新内容

- 修复司空航次没有 localEventId 时，报告首段城市监测数据整段留空的问题；按实际起止时间恢复唯一匹配的本地事件。
- 自动任务优先使用监测触发小时；没有可用监测事件小时的航次，使用实际起飞所在北京时间小时。报告分析时间同步显示对应小时。
- 各指标前值采用此前最近的有效值，可跨日；当前值必须来自对应小时，缺失时保留占位，不用旧值或未来数据补齐。
- 未确认的报告字段显示红色占位，保留模板字体及其他格式。

## 升级与验证

提供 macOS Apple Silicon / Intel 通用版、Windows x64 安装包及在线更新。本次未修改插件代码，插件版本保持 0.7.41。

发布流水线执行 Node、UI、双平台 Rust 测试、前端及安装包构建、updater 签名校验与 OSS 发布验证。真实报告样本重建与八页渲染验收见 docs/reviews/report-platform-hour-fix-2026-11-01.md。

运行客户端按钮验收、正式客户端实际 OTA 和 Windows 真机安装升级尚未完成。现有流水线未配置 macOS Developer ID 签名/公证或 Windows Authenticode 签名；updater 签名不等同于操作系统代码签名。
