# 0.2.14

修复 Windows 客户端隐藏到托盘后，再次双击桌面图标启动多个实例、争用本机连接端口的问题。再次启动将恢复已有窗口。正式版和测试版按应用标识分别限制实例。

升级前请通过托盘的“退出”关闭已经重复运行的旧版客户端；关闭窗口只会转入后台。首次升级后需在 Windows 实机确认托盘恢复、重复启动和在线升级行为。

本次基于 0.2.13 发布，仅加入单实例限制，不变更浏览器插件兼容要求。发布流水线运行前端及双平台 Rust 测试、构建安装包并验证 updater 签名。updater 签名不代表 Windows Authenticode 或 macOS Developer ID/公证。
