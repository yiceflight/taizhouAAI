# 0.2.17

- 巡飞报告采用最新模板，完善航线名称、照片分组、异常说明和监测统计；支持无照片及仅视频航次生成报告，省略空照片章节。
- 新增报告邮件设置，支持多个收件人、报告摘要邮件及重新发送。
- 改进报告缓存、历史数据读取及任务状态同步。
- 保留 0.2.14 的单实例保护，避免托盘后台重复启动导致桥接端口冲突。

随包 Chrome 插件及最低兼容版本均为 0.7.48。升级客户端后，在 Chrome 扩展管理页重新加载正式版插件，并确认实际运行版本；替换安装包本身不会自动重载扩展。

0.2.15 在 CI 报告截图测试中停止，未发布安装包或更新清单。0.2.16 修正过时的测试断言：平台截图仍按原始字节归档，但不追加到固定 Word 模板正文。

0.2.16 因版本更新误改第三方依赖锁定版本而停止，未上线。0.2.17 恢复原依赖锁，仅更新应用自身版本。
