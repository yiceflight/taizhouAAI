# 0.2.18

- 完善 Word 快报字体、刊头红线、表格与照片间距，以及落款日期和固定工作建议；异常数量与照片分组保持一致。生成 DOCX 无需安装 Office。
- 起飞失败且监测指标仍超阈值时，突出显示人工处理提示和核验后重新执行入口。
- 邮件配置改用本机文件保存，避免系统钥匙串授权弹窗，保留多收件人发送功能。原钥匙串中的自定义邮件配置不自动迁移，升级后请重新保存收件人及自定义发信设置。
- 随包 Chrome 插件及最低兼容版本均为 0.7.48；旧插件用户需在 Chrome 扩展管理页重新加载随包插件。当前版本不修改插件代码。

本地验证：179 项 Node 测试、265 项 UI 测试、5 项 Word 模板检查、TypeScript 和 Vite 正式构建通过。macOS 与 Windows Rust 测试、安装包构建和 updater 签名校验由正式发布流水线执行。

已有 Word 报告需重新生成才会应用新排版。字体显示和分页取决于阅读端字体；未进行 Windows 真机安装/升级验收。macOS 安装包沿用现有发布配置，未配置 Apple Developer 签名和公证。
