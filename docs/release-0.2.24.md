# 0.2.24

- 异常日志改为本地缓存，设置页新增「异常上报」按钮；用户明确点击后才通过已保存的 SMTP 账号发送，成功后清理对应缓存，失败时保留并允许手动重试。
- 支持将多批异常缓存合并为 ZIP 附件并按邮件大小分批发送，避免后台自动投递和重复发送。
- Airins 历史航线页面兼容路径规范化、尾斜杠和挂载后移除查询参数的情况，同时继续拒绝错误航次和非业务域名。
- 随包 Chrome 插件及最低兼容版本升级为 **0.7.61**。安装客户端后需在 Chrome 扩展管理页重新加载随包插件；版本文件更新不代表现有客户端或插件已加载该版本。
