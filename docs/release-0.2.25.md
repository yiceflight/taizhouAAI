# 0.2.25

发布日期：2026-11-11。客户端版本：0.2.25；随包及最低兼容 Chrome 插件版本：0.7.62。

- 清理升级后失去本地记录的托管计划、媒体、天气和可飞历史标签页，避免孤儿页面持续累积。
- 自动起飞不再把旧标签页中的核对浮层作为提交前置；旧插件因浮层缺失留下的同小时自动失败，在自动模式下安全重试一次。
- 保留司空平台自身的安全提示和提交回执校验，不自动绕过平台阻飞或人工确认弹窗。

本次通过 Node、UI、Rust 巡飞测试和前端构建。Windows 安装升级、Chrome 扩展实际重载和真实无人机起飞仍需在目标电脑现场确认；安装新客户端后请在 Chrome 扩展管理页重新加载随包插件，并确认运行版本为 0.7.62。
