# 0.2.26

发布日期：2026-11-11。客户端版本：0.2.26；随包及最低兼容 Chrome 插件版本：0.7.63。

- 自动生成报告首次保存成功后，使用已保存的收件人和 SMTP 配置自动提交报告邮件；已有报告重新生成不会重复自动发送。
- 重新发送报告时支持临时增加、删除和撤销收件人，不修改已保存的邮件设置。
- 修复轨迹图采集函数序列化后丢失路由校验依赖导致的 `ReferenceError`，并将插件执行错误转换为中文提示。
- Chrome 正式版和开发版插件版本升级到 0.7.63，客户端最低兼容版本同步更新。

验证：Node 测试、UI 测试、邮件模块 Rust 测试、TypeScript 检查和前端生产构建已通过。真实 SMTP 投递、Windows 安装升级和现场无人机验收仍需在目标环境确认。
