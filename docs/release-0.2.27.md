# 0.2.27

发布日期：2026-11-11。客户端版本：0.2.27；随包及最低兼容 Chrome 插件版本：0.7.64。

- 修复可飞浓度轨迹图触及地图边缘时必须人工缩小地图的问题。
- 插件会自动关闭异常预览、逐级缩小地图、等待图层稳定并重试轨迹图采集，最多自动恢复 4 次。
- 图像格式、尺寸、超时和裁剪失败都会清理预览状态，避免下一次重试读取旧图像。
- Chrome 正式版和开发版插件版本升级到 0.7.64，客户端最低兼容版本同步更新。

验证：Node 测试、UI 测试、Rust 单元测试、TypeScript 检查和前端生产构建已通过。真实平台轨迹图恢复、Windows 安装升级和现场无人机验收仍需在目标环境确认。
