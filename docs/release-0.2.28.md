# 0.2.28

发布日期：2026-11-12。客户端版本：0.2.28；随包及最低兼容 Chrome 插件版本：0.7.66。

## 低配置电脑：减少托管页面并主动恢复白屏

- 每次巡查任务使用的司空计划页在任务结束后自动关闭：提交成功的页面 2 分钟后关闭；提交失败或未提交的草稿，在客户端在线且不再查询该任务 30～60 分钟后关闭。此前这些页面会一直保留到手动关闭，是“App 托管”分组内司空页面累积的主要来源。禁止重复起飞的提交记录不受影响，始终保留。
- 托管页面的清理由“仅插件启动时一次”改为每 5 分钟一次。分组内无人使用且闲置超过 10 分钟的司空计划列表、媒体库、天气页和可飞任务图表页会被关闭；当前正在查看的页面、起飞计划草稿和分组以外的页面不会被关闭。
- “打开网站 / 打开并处理”改为切换到已有的同地址托管页面并刷新，不再每点击一次新增一个页面。
- 任务同步页、任务状态页在读取超时或列表一直未渲染时自动刷新一次（同一页面 2 分钟内最多一次），不再每轮在同一个白屏页面上失败。
- 任务同步页、天气页和健康检查页不再参与 Chrome 的自动休眠，被休眠的任务页会在下次读取时重新加载。
- 媒体页被休眠或一直未加载完成时，改为关闭并重新打开，不再让同一份报告反复失败。
- 状态查询页在没有巡查任务 30 分钟后关闭，下次查询时自动重新打开。
- 可飞页面唤醒后仍白屏或读数超时，在可见状态下主动刷新一次并复核结果，不再把未渲染的页面当作已验证。

## 自动报告

- 修复自动报告在后台标签页采集可飞曲线图时提示“显示区域不完整，请放大浏览器窗口”的问题：截图期间只临时激活插件自己创建的图表页，完成后恢复用户原标签页。
- 可飞图表面板被窗口裁切时，先收起再让平台按自身缩放重开一次；仍不适合的给出明确提示，不再每轮空转。

## 异常上报

- 手动上报附带最近 30 分钟完整运行日志、当前窗口尺寸/屏幕与托管标签页清单（页面地址只保留路由，不含参数、Cookie、存储和网页正文），并新增每次报告采集失败的结构化原因码。
- 巡查任务中自动生成失败的行新增“上报此问题”入口。
- 诊断记录在缺少浏览器全局对象时不再抛出 ReferenceError 打断业务路径。

Chrome 正式版和开发版插件版本升级到 0.7.66，客户端最低兼容版本同步更新。

## 使用提示

- “泰州监测 · App 托管”分组由 App 管理。需要长时间保留的司空或可飞页面，请拖出该分组后使用。
- 安装新客户端后，请在 Chrome 扩展管理页重新加载随包插件，并确认运行版本为 0.7.66。

验证：Node 测试 232 项、UI 测试 277 项、Rust 测试 222 项、TypeScript 检查通过。真实可飞页面截图、Windows 低配置电脑上的页面数量与白屏恢复、Windows 安装升级和现场无人机验收仍需在目标环境确认。
