# 0.2.29

发布日期：2026-11-12。客户端版本：0.2.29；随包及最低兼容 Chrome 插件版本：0.7.67。

## 自动起飞异常恢复

- 自动起飞在填写计划、准备页面或提交前就绪检查失败时，区分“未发送起飞请求”和“可能已经发送”。只有明确未发送的自动任务才会在同一超标小时内重新准备，最多 3 次；提交后的回执丢失、连接中断等不确定结果不会盲目重飞。
- 客户端在起飞倒计时期间关闭、更新或中断后，不再使用无人看守的旧倒计时直接起飞，而是重新检查司空页面、天气、禁飞规则和最新指标，再决定是否执行。
- 重试会保留原失败回执、来源小时、当前次数和下一次时间；运行日志显示“重新核对、自动重试、次数用完、可能已提交”等可操作原因。司空页面加载、休眠或超时等暂态问题会等待恢复，不会直接要求人工处理。
- 钾离子和 PM2.5 按各自观测时间参与判断，不会让较新的正常数据遮住仍在有效时效内的超标小时。

## 报告采集互斥

- 自动采集报告期间，对应任务行的“生成报告 / 重新生成报告”按钮锁定并显示“正在自动采集…”，点击不会打开第二个报告弹窗，也不会重复占用司空页面。
- 自动采集结束后按钮自动恢复；其他任务仍可查看已有报告。手动打开的报告会暂停新的后台自动采集，避免同步结果覆盖当前弹窗。

## 运行日志

- 前端异常日志使用用户可读的中文说明，同时保留结构化 `kind` 供诊断，不再把内部事件名直接显示给用户。
- 保留起飞失败、重试、倒计时中断等关键状态；重复的内部细节仍在诊断数据中，不堆在运行日志主列表。

Chrome 正式版和开发版插件版本升级到 0.7.67，客户端最低兼容版本同步更新。

## 验证

- Node 测试：233 项通过。
- UI 测试：276 项通过。
- Rust `flight` 模块新增自动重试、提交不确定、倒计时中断和指标时效测试；完整 Rust 测试及构建在发布前执行。
- 未在真实司空页面、Windows 机器或无人机现场触发超时/天气拒飞验收；发布后需在目标环境确认插件已重新加载并观察一次失败、日志和自动重试链路。

## 使用提示

- 安装新客户端后，请在 Chrome 扩展管理页重新加载随包插件，并确认运行版本为 0.7.67。
- 自动采集任务进行中请等待本次采集完成；采集失败时查看该任务行和运行日志中的具体原因。
