# 0.2.30

发布日期：2026-11-12。客户端版本：0.2.30；随包及最低兼容 Chrome 插件版本：0.7.69。

## 可飞浓度轨迹图

- 报告直接嵌入可飞平台导出的完整 PM₂.₅ 地图，不再从 PNG 像素颜色推断轨迹范围。
- 保留平台原图尺寸和完整航迹，避免底图颜色与色标相近时误判轨迹缺失或触及边缘。
- 客户端兼容整图导出元数据，同时继续读取旧版裁剪图缓存。

## 报告任务交互

- 后台自动采集期间只锁定正在采集的任务操作，其他任务显示正常操作状态并保持互斥。
- 诊断上报提示增加间距，改善设置页显示。
