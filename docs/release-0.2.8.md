# 0.2.8 正式版

发布日期：2026-10-26。客户端版本：0.2.8；随包及最低兼容插件版本：0.7.29。

## 更新内容

- 巡飞报告按实际执飞起止时间统计空气参数最高值和平均值，恢复六列现场照片表；原始数据、缺测信息和时窗外记录继续归档。
- 报告与预览图片合成司空动态温度标注，保留原图及完整性信息；第四章增加经过校验的可飞 PM2.5 时间曲线截图。
- 修复任务刷新影响报告操作、手动报告等待自动报告、迟到回执覆盖新报告等交互问题。
- 改善客户端隐藏到托盘后的监测与插件读取超时恢复，窗口恢复时立即同步状态。
- 支持 K⁺ 或 PM2.5 超过配置阈值触发巡查，新增配置的 PM2.5 默认阈值为 30 μg/m³；支持固定航线与按风向选择航线。已有用户保存的阈值继续使用原配置。

## 升级说明

- 提供 Windows x64 安装包及适配 Apple Silicon / Intel 的 macOS 通用安装包，同时通过客户端在线升级分发。
- 升级客户端后，请按客户端插件安装指引更新并在 Chrome 扩展管理页重新加载插件，确认运行版本为 0.7.29。旧插件会被兼容检查拦截。
- macOS 安装包具有 Tauri updater 签名，尚未配置 Apple Developer 签名与公证；首次安装可能需要在系统设置中允许打开。

## 验证边界

发布流程运行 Node、界面测试、前端构建，以及 Windows / macOS Rust 测试和安装包构建，并在更新 OSS 清单前验证 updater 签名。模板结构另由本地回归检查。

现有 macOS 隐藏窗口监测观测结果见 `background-monitoring.md`。Windows 实机安装与后台运行、最新报告完整重新采集至保存的客户端验收仍需现场确认，不能用自动化测试或构建成功代替。
