# 0.2.9 正式版

发布日期：2026-11-01。客户端版本：0.2.9；随包及最低兼容插件版本：0.7.38。

## 更新内容

- 修复司空已结束或部分执行任务仍占据当前任务区的问题，保留平台执行结果和失败原因。
- 修复手动巡查后错误消耗新一小时超标数据的问题，恢复自动巡查的 5 分钟倒计时；完善起飞回执同步。
- 天气用于记录及按有效风向选择航线，是否允许起飞由大疆平台决定；无有效风向时使用默认航线。
- 修复媒体已上传结束但持续等待照片的问题。完整读取后确认只有视频或照片目录为空时显示“无照片”，不生成报告；解析异常单独说明，支持重新读取。
- 支持读取航次根目录照片，核对分页、文件数量、航次身份和照片时间，避免遗漏或串用其他航次素材。
- 按既定模板填充巡飞快报，完善实际飞行时段统计、数据缺测处理和报告证据校验。
- 修复“更多”菜单被裁切、放大 PM2.5 超标图表标记，增加巡查任务未读提示，简化设置及运行状态界面。
- 完善插件版本兼容检查、并发读取、超时恢复及数据重置隔离。

## 升级说明

提供 Windows x64 和 macOS Apple Silicon / Intel 通用安装包及在线更新。升级客户端后，请按插件安装指引更新并在 Chrome 重新加载插件，确认实际版本至少为 0.7.38。

无照片航次不等于无媒体航次；视频仍保留在司空。对相同媒体解析结果，本次客户端会话不再反复自动采集；手动重新读取、媒体信息变化或下次启动可重新核验。

## 验证与边界

真实开发客户端已验证：PM2.5 超标进入倒计时并同步司空结果；已结束任务退出当前区；“上传结束 2/2、仅有视频”的航次显示无照片且未保存报告。本地最终回归：Node 161 项、UI 236 项、Rust 164 项、Python 模板 2 项通过（合计 563 项），Rust 另有 1 项原有忽略用例；TypeScript 和生产前端构建通过。双平台构建及 updater 签名由发布流程检查。

Windows 真机安装/升级、正式客户端的实际 OTA 升级尚需现场验收。macOS 未配置 Apple Developer 签名与公证，Windows 未配置 Authenticode 签名；updater 签名仅用于验证更新包，不能替代操作系统代码签名。
