# 0.2.2

- 重整监测工作台，增加插件及网站可用性检查、首批数据加载和连接恢复提示。
- 新增监测设置，支持调整 K⁺ 阈值、PM2.5 报告阈值、巡飞延迟和人工确认。
- 新增机场天气展示与天气条件检查；完善巡飞倒计时、取消、提交去重及异常恢复。
- 优化巡飞 Word 快报、监测图表和任务状态展示。
- 隔离开发版与正式版客户端、插件连接；增加旧插件持续提醒与兼容性限制。

- 修复 Windows 构建时因 CRLF 换行导致插件配置校验失败的问题。

## 升级说明

安装客户端更新后，请在 Chrome 扩展管理页重新加载随新客户端附带的 **0.7.1** 正式插件。旧插件在更新前无法开始采集和监测。

自动巡飞默认关闭，默认保留起飞前人工确认。计划提交回执不等于已起飞；真实司空提交和无人机飞行尚未验收。

本次发布提供 macOS Apple Silicon / Intel 通用 updater 包和 Windows x64 NSIS 安装包。安装包使用现有 Tauri updater 密钥签名；macOS Apple Developer 签名和 notarization 尚未配置。
