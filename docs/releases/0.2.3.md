# 0.2.3

- 统一客户端与插件品牌为“江苏省泰州环境监测中心智能监测系统”，附带 Chrome 插件 0.7.12。
- 完善监测、天气、手动起飞与自动巡飞设置，保留源站缺测小时，优化采集和插件连接状态提示。
- 修复人工确认、执飞异常、天气阻飞后的任务流转与历史归档，补充核查和结束本地任务的操作。
- 优化飞行报告列表、采集、保存与失败反馈，修正在线升级清单日期读取。
- 保留 Windows CRLF 构建兼容；构建流水线校验版本并运行 Node、UI 和两平台 Rust 测试。
- 增加独立的手动构建入口，交付 Windows x64 安装包和 macOS 通用 DMG/updater 包；仅推送版本标签时发布在线更新。

macOS 尚未配置 Apple Developer ID 签名与公证；Tauri updater 签名用于更新包校验。自动化测试和安装包构建不替代目标实机安装、插件重新加载、升级与真实巡飞验收。
