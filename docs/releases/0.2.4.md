# 0.2.4

- 统一巡飞报告生成窗口，支持无可飞数据时按司空实际航次生成照片报告、重新生成报告，以及从报告行定位 Word 文件。
- 按保留的原始 Word 模板填充快报，保留版式和表格结构；读取原图 EXIF/XMP 坐标与影像类型，保存可追溯来源和按照片哈希绑定的判读，缺少依据的字段保持空白。
- 同步司空已完成任务的实际起止时间，优化任务状态与历史展示，新增保留原始记录的任务列表清空操作。
- 简化任务天气展示，改善监测设置窗口的间距和滚动体验。
- 附带 Chrome 插件 0.7.14，修复司空身份验证对前端模块编号的依赖。本版最低插件版本同步提高至 0.7.14；升级后须在 Chrome 扩展管理页重新加载随客户端提供的插件。
- 包含 0.2.3 的品牌、监测、天气、任务流转与在线更新改进；0.2.3 曾提供构建包，本次统一发布到正式在线更新渠道。

提供 Windows x64 安装包和 macOS 通用安装包。macOS 未配置 Apple Developer ID 签名与公证，Tauri updater 签名用于更新包校验。自动化测试和构建不替代实机安装、升级、插件重新加载及真实巡飞验收。
