# 0.2.7

- 增加正式版与测试版客户端隔离，测试版使用独立应用标识、端口、数据目录和更新边界；补充环境、架构、运行日志与桥接诊断文档。
- 增加运行日志查看与导出、数据清理和窗口生命周期记录，便于定位客户端、插件和网站连接问题。
- 优化小时监测按图表时间范围补齐、天气检查、巡查计划同步、任务状态与飞行报告采集；未知媒体数量不再显示为 `0/0`，报告按实际时间关联并保留历史版本。
- 更新 DJI 任务、航线和报告页面适配，桥接插件升级到 `0.7.21`，正式客户端最低插件版本同步为 `0.7.21`。
- 提供 Windows x64 与 macOS 通用正式安装包及在线更新清单。macOS Apple Developer ID 签名、公证和目标机器安装、升级、插件重新加载与真实巡飞仍需在对应环境验收。
