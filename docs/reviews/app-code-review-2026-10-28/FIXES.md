## 修复结果

- **F1 分批历史清理**：插件提供每批实际扫描起止页与总数；客户端持久保存本轮已见任务编号，并串行执行游标同步。扫描连续、总数一致且完整收齐唯一任务编号后，才清除平台已不存在的旧缓存。失败保留已收到数据并从失败页继续；总数变化重新开始；缺页、数量不符或旧游标缺少扫描证据时不删除。记录、游标、扫描集合和删除动作位于同一 SQLite 事务，非法回执整批回滚。本地报告文件不参与删除。
- **F2 手动任务关联**：手动和演练任务改为查询 K⁺ 或 PM2.5 任一有效的最新小时，不再优先使用较早 K⁺。保留手动任务不依赖超标、同一来源小时可多次手动发起的既有规则。
- **F3 清空后界面残留**：清空成功立即使航线列表与选择失效，保留尚未保存的编辑草稿；选择航线、同步航线和清空共用操作锁，避免迟到选择回执恢复旧配置。App 在等待状态刷新前就通知报告界面重置，网页采集列表重新挂载并读取，旧列表请求不能重新填入已删除记录。
