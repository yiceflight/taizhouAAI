# 司空航次报告首段留空回归修复

问题：将城市小时数据查询依赖于本地自动触发事件，导致没有 localEventId 的司空航次整段统计留空，即使本地数据库已有监测值。

修复：先按航次实际起止时间恢复唯一匹配的本地事件（有 localEventId 时仍限制该 ID），自动事件优先采用 sourceHour / 旧版整点 observedAt。没有可用监测事件小时的航次采用实际起飞所在北京时间小时，归档 flightHour。查询截至该小时的有效城市数据；各指标前值可跨日，当前值仍必须来自当前小时，不回填旧值。

验证：36 项 Rust 报告测试、17 项 Node 报告测试、2 项 Python 模板检查通过；另运行真实归档重建测试 1 项。新增回归覆盖无本地事件的司空航次以及缺少 localEventId 时恢复延迟起飞事件的源小时。

真实样本：2026-11-01 17:00—17:24 航次，20 张照片，无机载空气数据。数据库通过只读连接备份到临时目录，报告独立重建，不覆盖原归档。首段为17时，PM2.5 30.00→31.00（3.3%），K⁺ 0.39→0.40，K⁺/PM2.5 1.30%→1.29%。过程次数及人工结论等未确认字段保留红色占位。

使用 bundled LibreOffice 和临时宋体字体映射渲染全部8页并检查；字体映射仅供验收，不改变模板字体。未进行运行客户端按钮验收，未主动启动、停止或重启开发服务。
