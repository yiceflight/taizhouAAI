# Word浓度轨迹图与自动裁剪

第四章表4前增加平台PM2.5点云浓度轨迹图，保持平台配色；图号接在大气站两图和照片组后。原图和裁剪图独立归档，无可飞模式不插图，旧空气缓存缺图则重新采集。

裁剪规则：识别平台色标对应的高饱和度浓度像素，合并全部色段范围，每侧加对应轴10%，至少48原图像素。并非地图坐标投影计算；同色地图物体可能扩大裁剪范围，异常缺图或轨迹触边则报错。待现场验证更复杂的混合色段、地图缩放及底图加载情况。

用户截图1654×1564，裁剪矩形x=486、y=180、width=752、height=1223，完整可见轨迹及起点；预览见report-trajectory-crop-2026-11-11.png。生成的测试Word共6页，已逐页渲染检查；这是布局样例，测试航次时间与附件地图不是同一真实航次，不作为业务报告交付。
