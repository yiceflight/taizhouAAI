# Windows 报告图片超限与未登录标签页累积

## 已定位与修改

- 天气采集在失败后约每 30 秒重试。旧实现仅复用 URL 完全等于天气页的标签，跳转登录页后重新建页，导致持续累积。修改为保留已记录的标签，跳转时提示完成登录，不继续建页；关闭该标签后允许重新创建。
- 飞行状态轮询复用带持久化标签 ID 的任务页管理器，登录跳转重试使用同一标签。
- 原始照片继续限制 12 MB。完整像素的带标注 PNG 单独允许 36 MB；截图、尺寸校正、原生校验、归档及 Word 嵌入同步适配。插件单次数据上限 66 MB、桥接 HTTP 上限 68 MiB，容纳原始照片及带标注图的 base64 与元数据。超过上限仍拒绝，不丢弃标注或缩小照片。
- 司空身份检测对网络错误及 HTTP 502/503/504 最多重试一次，两次共用原有 12 秒超时；401/403、页面切换、持续错误均不冒充成功。
- 插件及客户端最低版本同步提高到 0.7.49。

## 验证

- Node 全部 183 项测试通过，包括模拟 120 次未登录天气重试只创建一个标签、PNG 超过 12 MB 的截图与尺寸校正、36 MB 上限、身份检测重试与登录失败。
- 原生标注图片 4 项测试通过，包含实际生成大于 12 MB 的有效 PNG，验证校验、归档和 Word 嵌入的字节一致性。
- Rust 全量 200 项通过、3 项忽略、1 项失败：`flight_report::air_chart::tests::screenshot_is_archived_and_included_in_restored_report` 仍要求 Word 包含已移除的 PM2.5 曲线图片，查找该 ZIP 条目得到 FileNotFound。此次未修改该曲线模块和测试。
- `git diff --check` 通过。

## 交付边界

本次在已有大量未提交变更的工作区上做增量修改，没有提交、打包、发布或重启客户端。开始检查时本机 14520 为已安装正式客户端，未发现 1420 开发服务。未启动开发环境，未重载 Chrome 插件；未核验运行中的插件是否使用 0.7.49、运行中的客户端是否使用新的最低版本。

Windows 现场仍需用同一失败任务重新生成报告，并验证未登录持续运行、登录后恢复、不同屏幕/浏览器缩放。图片问题的确切 Windows 缩放触发条件以及历史“大疆异常”的原始错误尚未取得；代码路径与回归结果不等同于 Windows 实机验收。
