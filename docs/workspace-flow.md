# 运行环境与监测工作台

## 使用顺序

1. 启动桌面客户端。客户端默认进入监测总览；运行环境未就绪时自动弹窗，提供插件连接与网站登录处理入口。
2. 安装或重新加载客户端附带的 Chrome 插件（最低版本以 `bridge-config.json` 为准）。连接异常会区分插件未连接、旧版本、多浏览器会话、客户端端口冲突。
3. 插件连接后，客户端会自动在 Chrome 后台补开江苏大气站地图入口、大疆司空泰州项目页和可飞历史任务页；已有或正在加载的标签页会复用，不切换前台页面。登录过期时请在对应页面完成登录。弹窗在兼容插件及三个网站全部验证通过后自动关闭。
4. 江苏大气站与插件验证通过后，自动读取首批监测数据；环境异常时自动弹窗提示，恢复后自动读取数据并回到当前页面。

每个平台每次启动最多自动补开一次，避免异常重试不断创建标签页；点击“重新检查环境”可再次尝试补开仍缺失的平台。

每次重新启动客户端都重新验证工作环境，通过后自动开始监测，不沿用上次进程的登录验证结果。数据和历史报告保留；已启动工作台的连接恢复不会再次执行启动操作。

## 状态与恢复

- 插件：必须有且仅有一个兼容会话，没有本地连接服务错误。
- 网站：就绪、需登录、无权限、需打开业务页、检测异常分别显示。网络错误不会被误判成登录成功。
- 每秒检查插件连接及页面变化，连接成功或业务页变动后尽快验证；正常状态每 45 秒复查，异常状态每 30 秒复查。三站检查同时提交；插件 v0.7.35 起，只读检查不设并发数量上限，长任务运行时也会继续领取新检查。排队等待最多 120 秒，交付插件后才开始计算单站 35 秒执行期限，排队超时单独说明尚未执行检查；验证结果最多有效 120 秒，并绑定浏览器会话、标签页和页面 URL。界面每 2 秒读取状态，正在验证的行显示“验证中”，不把中间态显示成“待验证”。
- 江苏大气站就绪即可读取监测数据；巡查填写/起飞要求司空就绪且工作台已开始监测；完整报告要求司空与可飞就绪，纯照片报告只要求司空就绪。各项均要求兼容插件，任一平台失败仅阻止依赖它的操作。历史报告查看无需连接平台。
- 电脑从锁定或休眠恢复时，客户端立即强制刷新一次机场天气，再检查浏览器插件及三个业务网站；监测已启动且未关闭时随后补做小时数据同步。同步后的任务天气记录和风向选线使用本次恢复后的天气回执，避免沿用锁定前的旧数据。
- 恢复后保留当前工作位置和巡查提醒。原计划入口定位插件保存的原草稿标签页，不重新创建计划。
- 数据时间与同步时间分开显示。超过 3 小时或指标缺测时显示警告；只使用最近一条至少有一项有效值且不超过 3 小时的观测；K⁺ 缺测时，PM2.5 仍可独立触发巡查，两项均缺测不触发。

## 页面组织

- 监测总览：整体运行状态、三站状态、最新数值、数据质量、24/72/168 小时时间范围和图表/表格。
- 巡查任务：合并任务与报告，一个可飞任务对应一份 Word 报告。在任务行中生成或打开报告；未完成工作准备时仍可查看本机任务与报告。网页采集保留在折叠区。
- 顶部无人机状态区按阶段突出执行、取消、司空核查、实时监测或报告入口，辅助操作收进「更多」。只有起飞准备失败可确认「暂不执行」并收起提醒，执行中任务不提供归档入口。巡查任务页不再显示重复的任务控制卡、自动巡飞设置或航线演练。收起本机提醒不会终止飞行。
- 主导航仅保留监测总览、巡查任务、运行日志；删除独立运行状态页及其异常角标，不在设置中增加替代页面。环境异常由现有弹窗处理，业务页的「重新检查环境」直接触发验证。
- 底部状态栏不再重复显示浏览器连接和三个网站的验证状态，保留本地存储说明及版本、更新入口。

## 检测边界

固定只读适配器位于 `extension/src/site-health.js`：

- 江苏：在任一已登录页面复用全局 API 客户端读取泰州市指标目录，不要求切换网页路由；从现有同源标签页中选择真正通过接口验证的页面。
- 可飞：通过当前浏览器会话读取历史任务列表，必须取得成功业务返回。
- 司空（插件 v0.7.14 起）：在指定泰州项目页面内直接 GET 固定中国区官方地址 `https://es-flight-api-cn.djigate.com/manage/api/v1/users/current`，不依赖 Webpack、模块编号或内部 HTTP 客户端。只在 HTTP 成功、业务码为 0 且返回有效 `user_id` 时通过；存在令牌或打开项目页面本身不算登录成功。401/403、网络错误、无效响应与验证期间页面跳转均不放行。此检查不代表设备在线、具备起飞权限或媒体资料已经上传完成。

适配器不读取密码或 Cookie。司空身份验证仅在司空页面执行上下文内读取现有 `x-user-token`（优先）或 `x-auth-token`，仅作为请求头发送至上述固定官方 HTTPS 身份接口；不接受页面提供的任意地址，不跟随重定向，不记录或向插件、桌面客户端返回令牌、账号信息或完整响应。其他平台适配器不读取浏览器存储凭据。客户端只接收状态、说明和页面 URL。人工确认与填写演练只填写不提交；关闭人工确认的自动巡飞会在右侧核对面板倒计时结束后提交一次最终确认。
